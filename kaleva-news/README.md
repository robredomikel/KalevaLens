# KalevaLens multimedia production

Short audio summaries are generated by durable backend jobs after ingestion or final editorial approval. The Listen control only consumes ready `ArticleMedia` URLs; it never calls Gemini.

Required production configuration:

```bash
GEMINI_API_KEY=...
GEMINI_MODEL_NARRATION=gemini-2.5-flash
GEMINI_MODEL_AUDIO=gemini-3.1-flash-tts-preview
GEMINI_MODEL_MEDIA_QA=gemini-2.5-flash
MEDIA_AUDIO_ENABLED=true
MEDIA_MAX_AUDIO_DURATION_SECONDS=30
MEDIA_MAX_RETRIES=3
MEDIA_MAX_CONCURRENT_JOBS=2
MEDIA_JOB_TIMEOUT_MS=300000
MEDIA_JOB_SECRET=replace-with-a-long-random-secret
MEDIA_LANGUAGES=en
MEDIA_DEMO_MODE=false
MEDIA_AUTO_PROCESS_ON_START=true
MEDIA_WORKER_INTERVAL_MS=15000
MEDIA_STORAGE_ROOT=/absolute/path/to/kaleva-news/public/generated-media
MEDIA_PUBLIC_BASE_URL=/generated-media
```

`MEDIA_STORAGE_ROOT` defaults to `public/generated-media` for local development. `MEDIA_AUTO_PROCESS_ON_START=true` starts a local worker with the development server, processes the durable queue every `MEDIA_WORKER_INTERVAL_MS`, and periodically reconciles every published article until its audio is ready. Neon stores metadata and job state; MP3 files remain local and can be deleted after testing.

Run a scheduled worker (for example every minute) by making an authenticated `POST` request to `/api/media/jobs`. Add `?reconcile=true` for startup reconciliation/backfill:

```bash
curl -X POST -H "Authorization: Bearer $MEDIA_JOB_SECRET" \
  "https://your-kaleva-host/api/media/jobs?reconcile=true"
```

The reconciliation operation is idempotent. Jobs are unique by canonical article, article version, language, media type, and script version. Workers claim rows with `FOR UPDATE SKIP LOCKED`, recover stale locks, retry with exponential backoff, and never regenerate ready assets after restart.

For a complete end-to-end test, configure Neon, Gemini and local media storage; ingest an RSS item or approve an internal article; wait until its audio job is `ready`; load the feed; and verify Listen plays the stored MP3 URL. The narration agent synthesizes the title, full authorized article content, context, and source into a concise explanation; speech and encoding remain capped at 30 seconds. `npm test` uses no live Gemini access and creates and validates a real MP3 through FFmpeg.
